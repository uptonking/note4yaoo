## [Using Ghostty for the first time | amanhimself.dev _202603 ](https://amanhimself.dev/blog/using-ghostty/)

```toml

# Theme
# theme = light:Gruvbox Light,dark:dracula
theme = Gruvbox Light

# Contrast，可以让低色差的文字正常显示， 比如timestamp, 1.1不行, 1.2/1.3可以
minimum-contrast = 1.3

# Font
font-family = JetBrainsMono Nerd Font
font-size = 16
font-thicken = true

# Window
macos-titlebar-style = tabs
window-padding-x = 8
window-padding-y = 4
background-opacity = 0.96
background-blur = 10
unfocused-split-opacity = 0.6
window-padding-balance = true

# macOS
macos-option-as-alt = left

# Cursor
cursor-style = bar

# Mouse
mouse-hide-while-typing = true
```
