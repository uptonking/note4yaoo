# changelog

- v0.7.0 - 2026-08-31
  - Changed the project license to Apache-2.0
  - Added plugin installation and updates directly from Git repositories
  - Added SSH connections to existing remote daemons from Desktop and CLI 
  - Changed the default mobile content text size from 15px to 16px 

- v0.6.0 - 2026-08-25
  - Restored the dedicated Explorer sidebar with Files and Changes by default, replacing the empty user-directed Side panel introduced in 0.5.0 
  - Changed content opened to the side to use an ordinary closable workspace pane instead of the Explorer sidebar
  - Added standalone Diff tabs while keeping an optional persisted inline-diff mode in Changes

- v0.5.0 - 2026-08-23
  - Added experimental trusted local plugins 
  - Added a user-directed Side panel with independent tabs

- v0.4.0 - 2026-08-13
  - Removed paseo chat and paseo loop
  - Added host-wide agent profiles for reusable provider, model, mode, thinking, and feature settings

- v0.3.0 - 2026-08-08
  - New mobile terminal with text selection, copy, paste, and faster rendering
  - Search your history by workspace, agent, and branch 

- v0.2.0 - 2026-07-24
  - Work with pull requests and merge requests from GitLab, Gitea, Forgejo, and Codeberg
  - Edit files directly in the web and desktop apps
  - Oh My Pi (OMP) as a native agent provider
  - Open the complete Changes view as a workspace tab
